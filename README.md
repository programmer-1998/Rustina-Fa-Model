## 🌟 معرفی پروژه

**Rustina V1 Fa** یک مدل زبانی فشرده و بهینه‌سازی‌شده (۰.۶B پارامتر) است که با هدف اجرای فوق‌العاده سریع، آفلاین و روان بر روی پردازنده‌های معمولی (CPU) بدون نیاز به کارت گرافیک طراحی شده است. 

این مدل بخشی از **اکوسیستم هوش مصنوعی ماژولار راستینا** است؛ سیستمی که در آن هر ماژول به صورت مستقل، سبک و تخصصی روی یک حوزه فعالیت می‌کند:
* 🇮🇷 **ماژول تخصصی زبان فارسی (`Rustina-V1-Fa`):** تسلط بر درک متن، ادبیات، نگارش رسمی، ضرب‌المثل‌ها و مکالمه فارسی.
* 🇬🇧 **ماژول تخصصی زبان انگلیسی (`Rustina-V1-En`):** در حال توسعه (به زودی).
* 🐍 **ماژول تخصصی برنامه‌نویسی پایتون (`Rustina-V1-Python`):** در حال توسعه (به زودی).
* 🌐 *سایر زبان‌های گفتاری و برنامه‌نویسی نیز در صورت درخواست کاربران افزوده خواهد شد.*

## 🚀 نحوه اجرای سریع و آسان (Instant Runner)

فایل‌های اسکریپت آماده در همین ریپازیتوری قرار دارند تا کاربر بدون درگیر شدن با تنظیمات پیچیده، مدل را با یک دستور اجرا کند:

### الف) لینوکس و مک (Linux / macOS):
پس از قرار دادن فایل `Rustina-V1-Fa-Q4_K_M.gguf` در کنار اسکریپت‌ها، در ترمینال دستور زیر را اجرا کنید:
```bash
bash run.sh
```
*این اسکریپت به صورت خودکار فایل را بررسی کرده، موتور سبک را متصل می‌کند و صفحه چت تعاملی را برای شما باز می‌کند.*

### ب) ویندوز (Windows):
کافی است روی فایل زیر دو بار کلیک کنید یا در CMD اجرا نمایید:
```cmd
run.bat
```

### ج) استفاده در کدهای پایتون (Python Integration):
اگر برنامه‌نویس هستید و می‌خواهید از این مدل در پروژه‌ها یا ربات‌های پایتونی خود استفاده کنید:
```bash
python3 example_python.py "سلام! خودت را معرفی کن."
```
