# Rustina V1 - Persian Expert AI Model (راستینا) 🇮🇷⚡

**مدل هوش مصنوعی سبک، سریع و تخصصی زبان فارسی (Rustina V1 Fa)**  
توسعه داده شده توسط **سینا خانزاده** ([sina-khanzadeh.ir](https://sina-khanzadeh.ir)) تحت برند **راستینا (Rustina)**.

## 🌟 معرفی پروژه

**Rustina V1 Fa** یک مدل زبانی فشرده و بهینه‌سازی‌شده (۰.۶B پارامتر) است که با هدف اجرای فوق‌العاده سریع، آفلاین و روان بر روی پردازنده‌های معمولی (CPU) بدون نیاز به کارت گرافیک طراحی شده است. 

این مدل بخشی از **اکوسیستم هوش مصنوعی ماژولار راستینا** است؛ سیستمی که در آن هر ماژول به صورت متمرکز و تخصصی روی یک حوزه فعالیت می‌کند:
* 🇮🇷 **ماژول تخصصی زبان فارسی (`Rustina-V1-Fa`):** تسلط بر درک متن، ادبیات، نگارش رسمی، ضرب‌المثل‌ها و مکالمه فارسی.
* 🇬🇧 **ماژول تخصصی زبان انگلیسی (`Rustina-V1-En`):** در حال توسعه (به زودی).
* 🐍 **ماژول تخصصی برنامه‌نویسی پایتون (`Rustina-V1-Python`):** در حال توسعه (به زودی).
* 🌐 *سایر زبان‌های گفتاری و برنامه‌نویسی نیز در صورت درخواست و استقبال کاربران افزوده خواهد شد.*

## 🚀 بهترین روش اجرا: موتور اختصاصی `llama.rs`

برای دستیابی به حداکثر سرعت و بهره‌وری، توصیه اکید می‌شود این مدل را با موتور استنتاج فوق‌سبک **[llama.rs (Rustina Llama)](https://github.com/RustinaCo/llama.rs)** اجرا کنید:

```bash
# کلون و بیلد موتور راستینا (تنها ۱ مگابایت، بدون نیاز به C++):
git clone https://github.com/RustinaCo/llama.rs.git
cd llama.rs
cargo build --release

# اجرای حالت گفتگوی تعاملی با حافظه فعال:
./target/release/rust-llama run Rustina-V1-Fa-Q4_K_M.gguf -i
```

### ویژگی‌های کلیدی در اجرا با `llama.rs`:
* **سرعت استنتاج:** ۲۸ الی ۳۴ توکن بر ثانیه روی پردازنده معمولی (Intel i5).
* **زمان بارگذاری آنی:** لود اولیه مدل در کمتر از ۶۰ میلی‌ثانیه!
* **مصرف رم بسیار ناچیز:** تنها حدود ۳۵۰ تا ۴۵۰ مگابایت رم.
* **حافظه مکالمه جلسه (Multi-turn Context):** حفظ زمینه بحث در طول چت (با قابلیت دستور `/clear`).
* **حافظه ماندگار بین نشست‌ها (`--memory`):** امکان ذخیره اطلاعات کاربر با دستور `/save <اطلاعات>`.
* **مسیریابی ماژولار (Modular Router):** اتصال هوشمند بین ماژول‌های فارسی، انگلیسی و پایتون.
